# TCM Books - 中医经典文献库

为 Yuan App 项目存储的中医经典著作和文献数据库。

## 包含的著作

### 经典四大医书

1. **黄帝内经** (Yellow Emperor's Inner Classic)
   - 时代: 战国-秦汉
   - 重要性: 中医理论的奠基之作

2. **伤寒论** (Treatise on Cold Damage)
   - 作者: 张仲景
   - 时代: 东汉
   - 重要性: 中医临床实践的重要指南

3. **金匮要略** (Essential Prescriptions)
   - 作者: 张仲景
   - 时代: 东汉
   - 重要性: 杂病治疗的经典著作

4. **本草纲目** (Compendium of Materia Medica)
   - 作者: 李时珍
   - 时代: 明代
   - 重要性: 中医药学的百科全书

5. **四诊宝鉴** (Treasure of Diagnostics)
   - 时代: 晋代
   - 重要性: 诊断理论的重要著作
